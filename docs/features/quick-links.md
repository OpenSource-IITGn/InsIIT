# Quick Links

**What it does.** A set of handy links to frequently used campus web services
(webmail and similar).

**Where the code lives.**

* `lib/data/quickLinksContainer.dart` - `QuickLinksContainer`.
* `lib/quickLinks/screens/email.dart` - the quick-links screen.

**How it gets data.** The list of links is stored in a Google Sheet and loaded
through the container.

**Route.** `/Quicklinks`.
