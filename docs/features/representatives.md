# Student Representatives

**What it does.** Lists the student representatives and their details so
students know who to reach out to.

**Where the code lives.**

* `lib/data/representativesContainer.dart` - `RepresentativesContainer`.
* `lib/representativePage/screens/representativePage.dart` - the screen.
* `lib/representativePage/classes/representatives.dart` - the model.

**How it gets data.** Representative details are maintained in a Google Sheet.

**Route.** `/representativePage`.
