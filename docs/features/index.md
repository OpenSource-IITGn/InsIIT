# Feature Overview

InsIIT is organised as a set of independent features, each with its own data
container and screens. This section documents each one: what it does, where its
code lives, and how it gets its data.

| Feature | Status | Data source |
| --- | --- | --- |
| [Mess Menu & Feedback](mess-menu.md) | Stable | Google Sheets |
| [Class Schedule & Calendar](schedule.md) | Stable | Google Sheets + Calendar/Classroom |
| [Shuttle / Bus](shuttle.md) | Stable | Google Sheets |
| [Campus Map](map.md) | Stable | Google Maps |
| [News Feed](feed.md) | Beta | Node.js + MongoDB |
| [Room & Equipment Booking](booking.md) | Alpha | Sheets + backend |
| [Important Contacts](important-contacts.md) | Stable | Google Sheets |
| [Quick Links](quick-links.md) | Stable | Google Sheets |
| [COVID-19 Information](covid.md) | Stable | Google Sheets |
| [Notifications](notifications.md) | Stable | Firebase Cloud Messaging |
| [Student Representatives](representatives.md) | Stable | Google Sheets |
| [Misc & Developers](misc.md) | - | In-app |

The status column reflects the project README's own release stages
(Stable / Beta / Alpha).
