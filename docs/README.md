# InsIIT Documentation

**InsIIT** is the official open-source student app of **IIT Gandhinagar (IITGN)**.
It is a Flutter (Dart) mobile application for Android and iOS that brings the
services students use every day into one place: the mess menu, the daily class
schedule, shuttle bus info, campus maps, important contacts, quick links, a
news feed, room/equipment booking, and more.

The project is free and open source (GNU GPL-3.0) and is developed by the
**insIIT Developers Community**. Contributions of any kind are welcome.

This documentation set is written to be dropped straight into
[GitBook](https://www.gitbook.com/): the table of contents lives in
[`SUMMARY.md`](SUMMARY.md) and every page is a plain Markdown file.
